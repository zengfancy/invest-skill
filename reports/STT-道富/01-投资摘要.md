# 1. 投资摘要｜道富（STT）

> 上市地 US。财务时点 FY2025 + 3Q26；行情 2026-10-21；催化 2026-10-22。  
> 框架 **value-leader-research**。不构成投资建议。

## Step 0 资格

| 项 | 结论 |
|----|------|
| 标的 | State Street / 道富，NYSE: **STT** |
| 生意 | 全球托管与资服龙头之一 + 指数/ETF 资管（SPDR 等） |
| 为何 value-leader | 持续盈利、份额前列、定价吃费率/利差/经营杠杆，非题材；非未盈成长 |
| 为何不用 platform | 有 Alpha/数字化延伸，但主叙事仍是托管规模费用 + 资产负债表 NII，非「成熟主业+颠覆 SOTP」主问题 |
| 市值量级 | ~$46B，准大盘金融；非小市值 |

## 一句话匹配

托管 AUC/A 约 **$59T**（全球前二梯队）、资管 AUM **$6.3T**，经营杠杆与 ROTCE 改善明确；现价 **前瞻 PE ~11、PB ~1.9、股东收益率 ~5.6%**，更像**费率与市场贝塔驱动的价值金融股**——近端跌因是「收入/费用指引略逊预期 + 现金流出」，不是托管份额崩塌。

## 结构标签

| 业务 | 角色 |
|------|------|
| Investment Servicing（托管/基金行政等） | **成熟现金牛**；费用主力 |
| Investment Management（指数/ETF/现金等） | 成熟+份额争夺；费率压力长期存在 |
| Markets（FX/证金）+ Software（Charles River 等） | 杠杆与交叉销售 |
| NII | 存款与证券组合；利率路径敏感 |
