# 3. 近 1–2 年重大变化｜微软（MSFT）

> 本分册对应 Step 3。上市地 US。催化检索至 2026-10-22。不构成投资建议。

## 3.1 转折时间线

| 时间 | 事件 | 财务/经营印证 | 周期/结构 |
|------|------|---------------|-----------|
| 2024-08 | 分部管理口径调整（内部汇报重分类） | 历史分部已重述可比 | 结构（披露） |
| 2025-10-29 | FY26 Q1：Capex 创纪录 ~$34.9B，指引全年更高；Azure 高 30% 档 | 盘后跌；OpenAI 权益法拖累 ~$3.1B | **结构**：资本密度跃升 |
| 2026-01 | FY26 Q2：Azure ~39% 略逊抬高预期；自用产能优先 | 次日股价约 −10%（CNBC） | 结构+预期差 |
| 2026-06 | Mag7/AI capex 重定价；MSFT 单月约 −17%~−22%，2000 年以来最差月之一 | 月收 ~$372；盘中低点约 $349 | **结构**：FCF 溢价重估 |
| 2026-07-29 | FY26 全年：收入 $332B、Azure 年入过 $100B；Q4 Azure+其他云 +43% | 盘后约 +8%；股价自低点修复 | 结构确认需求 |
| 2026-09 | 首次披露 Azure 美元收入；预告并表为「Agents & Infra」+「Devices & Consumers」 | Azure Q4 $29.42B / 年 $101.9B | 披露结构 |
| 2026-10 | 股价再创纪录；Maia 200 量产、Maia 300 规划；临近 FY27 Q1 | 10-13 收 $543.45；10-21 收 $532.95 | 叙事修复 |

## 3.2 周期 vs 结构

| 类型 | 内容 |
|------|------|
| 结构 | AI 基建 capex 常态化；Azure 从「增速百分比」进入「千亿收入」；Copilot 付费席位规模化（管理层称 >3000 万）；OpenAI 投资从亏损扰动转为 FY26 净利增益；Xbox 减值/裁员压力 |
| 周期 | 2026 年中科技股整体回撤；OEM PC 周期拖累 Windows；个别季度产能约束导致 Azure 环比指引「减速预期」 |

**结论：** 过去两年最大难逆变化是 **「高 ROIC 软件公司 → 高资本密度 AI 平台」的资产负债表与 FCF 画像切换**，而非某一季收入失速。

## 3.3 检查清单

| 项 | 状态 |
|----|------|
| 新品类（Copilot / 自研模型 / Maia） | 有，规模化中 |
| 渠道/入口 | 云与办公入口强化；搜索/广告仍跟进 |
| 回购分红 | 持续；FY26 回购 $22.3B + 分红 $26.4B |
| 组织/提效 | Xbox 减值与自愿退休等；整体 OpEx +7% |
| 监管 | 云/AI/反垄断持续背景风险（未见单一决裂事件主导近端定价） |
| 并购 | Activision 已并入前序年份；近两年主线是内生 capex |

## 3.4 与市场预期

- **已定价：** Azure 高增 + AI 领导地位叙事（2024–2025 高位）。  
- **2026 中曾重定价：** Capex/FCF 与「回报时滞」。  
- **当前（2026-10）部分修复：** Q4 加速与 Azure 披露透明度；**尚未完全消化**下一季 capex 指引与 OpenAI 条款演变。
