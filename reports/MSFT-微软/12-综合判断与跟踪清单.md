# 12. 综合判断与跟踪清单｜微软（MSFT）

> 本分册对应 Step 12。框架 platform-leader-research；上市地 US。不构成投资建议。

## 12.1 一句话匹配（强制）

分板块质量高（PBP 利润锚宽、Azure 已过千亿美元且加速），颠覆敞口中高（主在 **capex 回报时滞与入口代际**），成长情景中性仍双位数但低于最乐观卖方，SOTP 中性略高于现价——**更像「优质平台在 AI 资本周期中的合理偏贵」，而非无锚纯故事。**

## 12.2 摘要回扣

| 回扣 | 要点 |
|------|------|
| 04 成熟主业 | PBP ~54% 经营利润、~60% 利润率，是估值锚 |
| 05 颠覆 | 最危险：capex/FCF 与办公入口 AI 化被旁路 |
| 06 护城河 | 办公宽、云中偏宽但「贵」、MPC 弱 |
| 08 情景 | 集团收入中性 14–17% CAGR；云贡献方差 |
| 09 SOTP | 中性隐含 ~$4.35T vs 市值 $3.96T；FCF yield 仅 1.7% |
| 11 涨跌 | 2026-06 叙事杀估值；2026-07 基本面修复 |

**乐观对照：** Azure 持续 40%+ 且 capex/收入比下降 → 期权溢价扩张。  
**谨慎对照：** Azure 减速 + FCF 再恶化 → 倍数二次压缩（可快于盈利下修）。

## 12.3 前提与风险

**中性前提：**  
1. 企业云与 AI 需求不陷入支出冻结  
2. M365 价格/Copilot 转化维持双位数 PBP 增长  
3. Capex 增速逐步低于收入增速  
4. 无恶性监管拆解办公+云捆绑  

**风险（可证伪）：**  
1. 连续两季 Azure 显著低于指引  
2. Cloud 毛利率失速下滑  
3. OpenAI 关系导致 Azure 消耗或 IP 条款恶化  
4. Xbox/终端出现更大减值拖累叙事（次要）

| 信号 | 看多确认 | 看空确认 |
