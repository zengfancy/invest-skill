# 10. 市场看法如何演变｜微软（MSFT）

> 本分册对应 Step 10。催化时点 2026-10-22。不构成投资建议。

## 10.1 证据类型

| 类型 | 内容 |
|------|------|
| 卖方 | 56 位分析师，共识 Strong Buy，目标价均值 **$599**（约 +12% vs $533） |
| 业绩与指引 | FY26 收入/利润双强；但 2025-10 起 capex 指引上修反复冲击 |
| 媒体归因 | 2026-06「史上级」回撤主因 AI 开支/FCF；2026-07 Azure 加速后修复 |
| 公司动作 | Azure 美元披露、分部将改组、Maia 自研芯片路线 |

## 10.2 叙事时间轴（近 1–2 年）

| 阶段 | 主题一句 |
|------|----------|
| 2024–2025 高点 | 「AI 平台必赢 + 无尽 Azure」溢价 |
| 2025-10～2026-01 | 「需求仍在，但 capex 与产能约束」开始计价 |
| 2026-02～06 | 「FCF 溢价消失 / Mag7 轮动」——倍数压缩主导 |
| 2026-07～10 | 「Azure 再加速 + 披露透明」修复；临近财报再博弈增速 |

## 10.3 卖方 vs 定价结果

- 卖方多数维持买入、上调长期目标（如 UBS 等将目标上调至更高），**与 2026 中股价背离**——基本面未崩、倍数先崩。  
- 2026-07 后股价与卖方乐观叙事重新同向。  
- 现价相对目标价均值仍有双位数「卖方上行空间」，但目标价**不是**本报告结论。

## 10.4 预期差（必写）

| 对照 | 判断 |
|------|------|
| Step 8 中性收入 CAGR 14–17% vs 卖方约 20% | **本中性更低** → 若卖方过度外推，存在下修风险 |
| 市场近期焦点 | Azure 能否持续 **>40%**（Motley Fool 等强调 10-28 看点） |
| 差在主业还是新业务 | **差在云/AI 期权厚度与 capex 峰值时点**；PBP 分歧较小 |
