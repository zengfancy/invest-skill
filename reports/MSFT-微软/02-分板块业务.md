# 2. 分板块业务｜微软（MSFT）

> 本分册对应 Step 2。上市地 US。财务时点 FY2026（2026-06-30）。  
> 框架 platform-leader-research。分部口径：年报/业绩稿 **Operating Income**。不构成投资建议。

## 2.1 集团如何赚钱

微软靠 **订阅与云用量** 赚钱：企业买 Microsoft 365 / Dynamics / LinkedIn 席位与广告，在 Azure 上买算力与平台服务，再叠加 Windows OEM、Xbox、Bing 搜索广告等终端业务。现金牛在 **Productivity（尤其 M365 Commercial）**；增长与资本密度在 **Intelligent Cloud（Azure）**；More Personal Computing 贡献规模但利润占比已降至约一成。AI（Copilot、模型推理、自研 Maia）同时依附于 Productivity 与 Cloud，并抬高集团资本开支。

| 指标 | FY26 | FY25 | YoY |

**纪律：** OpenAI 股权投资损益已显著扰动 GAAP 净利（FY26 净利因 OpenAI **+约 $5.0B**；FY25 为 **−约 $3.6B**）。经营质量以分部经营利润与 Non-GAAP EPS 对照。

## 2.4 小结

- **强项：** 两大板块收入均过 $130B；经营利润率集团约 47%；云与商业订阅飞轮完整。  
- **隐患：** Capex 近翻倍压制 FCF；MPC 收入负增长；GAAP 净利受 OpenAI 投资波动。  
- 不做增速外推与 SOTP（→ 08/09）。
