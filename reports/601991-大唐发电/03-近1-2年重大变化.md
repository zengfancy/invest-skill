# 3. 近 1–2 年重大变化｜大唐发电（601991）

> Step 3。写已发生的变化；未来增速见 [05](./05-成长性预测.md)。

## 核心问题

过去两年，**赚钱方式没有换**：仍是电量×电价−燃料−利息。变的是煤价（周期）和装机结构/分红/定增（弱结构）。没有出现「从火电公司变成算力公司」这种不可逆质变。

## 3.2 周期 vs 结构

**主结论：近两年是周期修复，不是商业模式切换。**

- **周期：** 2025 年煤机利润总额 56.25 亿（+119%）几乎一一对应入炉煤价 −14.8%。电价在降，公司没有定价权。2026H1 煤机已 −17.4%，周期开始回吐。
- **弱结构：** 清洁装机升到 43%；H1 水电利润 +42.7%、铝电净利 8.06 亿，让合并利润在煤机回落时仍能增长。这是来水与铝价，不是收费方式换成别的生意。
- **资本配置结构：** 从「亏损年少分红」到 2025 年现金分红约 27 亿、2026 中期再派 12.6 亿；同时启动 80 亿定增扩煤电/补流。一边分红一边再融资，是火电央企常见组合，会摊薄 EPS。

未见：主业改成算力、重大资产重组、客户结构突变、会计政策导致的利润台阶。

## 3.3 检查清单

| 项 | 结论 |
|----|------|
| 收入增速拐点 | 营收 2021–25 在 1036–1235 亿震荡，**未见收入台阶** |
| 净利拐点 | 2023→2025 是利润率拐点，不是收入拐点 |
| 产品/技术代际 | 煤电「三改联动」+ 风光基地，渐进，非代际颠覆 |
| 客户/出海 | 电网与国内市场化用户为主，未见出海结构 |
| 营运资本 | 应收稳定；合同负债季节性；存货是煤 |
| 竞争财务痕迹 | 电价连续两年下降 = 买方（市场）议价的痕迹 |
| 管理层战略 | 仍是综合能源；CapEx 每年 200–300 亿维持 |
| 盈利质量 | 扣非 ≥ 归母；联营收益 2025 年 20 亿，需盯 |
| 资本配置 | 分红回升 + 定增；**未见回购** |
| 治理/股本 | **定增是近端最大股本事件** |

## 3.4 与市场预期

周期修复（煤价）**已被 2024–25 年报和 PE 压缩充分反映**。尚未被当作「已兑现结构」的，是：定增落地后的摊薄、2026 年电价继续下行时利润能否保住、铝电能否重复 8 亿。5 月「算电」叙事被异常波动公告自己打了折扣，不应再当成基本面增量。
