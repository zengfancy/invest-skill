读法：

3. PS 9.0 仍显著高于综合药企（复星 PS 1.35），说明市场仍按创新平台而非仿制药给分子。

## 8.2 A 轨细节：Forward PE 与 PEG

| 项目 | 数值 | 口径 |
|------|------|------|
| 现价 | 42.67 | 腾讯 |
| 共识 EPS 2026 / 27 / 28 | 1.41 / 1.65 / 1.96 | 同花顺，28 家 |
| Forward PE 2026 | **30.3** | 42.67 / 1.41 |
| Forward PE 2027 | **25.9** | 42.67 / 1.65 |
| Forward PE 2028 | **21.8** | 42.67 / 1.96 |
| 共识 EPS CAGR 2026–28 | **≈17.9%** | √(1.96/1.41)−1 |
| **PEG（主）** | **≈1.69** | 30.3 / 17.9 |
| 若用 Step 7 中性净利 CAGR 15% | PEG ≈ **2.02** | 敏感性 |
| 若用中性净利 CAGR 18% | PEG ≈ **1.68** | 与共识接近 |

解释：

- PEG ~1.7（共识）对创新药龙头属 **中性偏贵到合理上限带**——要求增长大致兑现共识。  
- 若 2026 收入继续零增、扣非负增，则分母（EPS）下修，Forward PE **被动抬升**，「历史低 PE 分位」可与「不便宜」并存。  
- PB-ROE 可选：五年 ROE 并非全部取得；已知 2023–25 加权 ROE 10.99% / 14.73% / 14.26%。粗算近年 ROE 中枢约 13%–14% / PB 4.39 ≈ **3.0%–3.2%** 量级——对成长股仅作辅参考，**不作主结论**（框架非价值龙头 PB-ROE）。

读法：今日定价对 **「倍数不继续压缩」** 敏感。历史分位极低，提供的是「泡沫已挤」的相对舒适，不是「低估必涨」的安全垫。

## 8.5 「贵 / 便宜」必须说清相对什么

| 相对维度 | 判断 |
|----------|------|
| 相对自身历史 | **极低分位**（PE/PB/PS）——泡沫期对照下不便宜以外的回归 |
| 相对增长（共识） | Forward PE~30、PEG~1.7 → **中性定价，增长必须兑现** |
| 相对增长（本中性） | PEG~1.7–2.0 → 略更贵或中性偏贵 |
| 相对同业 | 仍持创新龙头溢价（高于复星，PS/PB 高于科伦） |

**综合：** 路由 A 下，恒瑞是 **「历史估值回归后的成长股中性定价」**，不是深度价值；也不是 2025 峰值那种透支高增的贵。若 Step 7 悲观情景出现，低分位无法阻止再定价。
