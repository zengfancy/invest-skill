# 4. 行业空间与竞争格局｜特斯拉（TSLA）

> Step 4。不构成投资建议。

## 4.1 空间桥（必须有桥）

| 层 | 内容 |
|----|------|
| TAM | 全球乘用车电动化 + 电网储能 + 未来 Robotaxi 里程 / 人形机器人 |
| 可参与 | 特斯拉已有工厂、充电、软件栈与数据闭环 |
| 产品 | 3/Y 为主的乘用车；Megapack；FSD 订阅；Cybercab；Optimus（早期） |
| 份额 | 全球纯电仍居前列但区域竞争加剧（中国新势力、传统车企 BEV） |
| 收入 | **近端**靠车+储能+服务；**远端期权**靠 Robotaxi/机器人——不可并入近 3 年确定性收入 |

禁止：「出行市场很大所以值 1.5T」。

## 4.2 竞争

| 赛道 | 主要对手 | 烈度 |
|------|----------|------|
| 量产 BEV | BYD、传统 OEM 电动车、新势力 | **高**（价格与功能） |
| 储能 | 阳光电源、Fluence、传统电力设备商等 | 高 |
| 智驾 | Waymo、传统车企+供应商、Robotaxi 新创 | 高；监管与安全决定节奏 |
| 人形机器人 | Figure 等早期玩家 | 格局**未定** |

## 4.3 集中度/市占

精确全球市占本报告**未统一取得第三方权威表**（缺口）。经营事实：FY25 交付约 164 万仍属全球头部 BEV；但同比下滑显示份额/需求压力。Robotaxi 仍极早期，市占无意义。
