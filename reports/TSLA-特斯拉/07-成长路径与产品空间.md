# 7. 成长路径与产品空间｜特斯拉（TSLA）

> Step 8 估值 PEG/路径须引用本步。不构成投资建议。

## 7.1 收入桥（中性）

```text
乘用车：交付温和复苏 + ASP 承压 → 收入低个位数～高个位数
+ 储能：GWh 与 ASP → 收入双位数
+ 服务/充电/保险：随车队 → 双位数
+ FSD 订阅：席位×ARPU → 高增但基数仍小
+ Robotaxi/Optimus：T+1～T+3 以「期权」计，不并入中性主表大额
```

## 7.2 情景（T+1～T+3）

| | 收入 CAGR | 经营利润率路径 | 触发 |
|--|-----------|----------------|------|
| **中性** | **8–14%** | 缓慢回升至中高个位数 | 车交付恢复；储能持续；FSD 渗透；OpEx 增速 ≤ 收入 |
| 乐观 | 15–22% | 利润率明显扩张 | Robotaxi 付费英里规模化；汽车 ASP/量双升 |
| 悲观 | 0–5% | 利润率再下台阶 | 价格战；监管拖延；AI 投入无回报 |

对照卖方：3Y 收入约 **15%**、EPS 约 **23%**（StockAnalysis）——接近乐观/中性上沿；**本中性略低**。
