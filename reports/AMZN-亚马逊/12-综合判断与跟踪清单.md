# 12. 综合判断与跟踪清单｜亚马逊（AMZN）

> 本分册对应 Step 12。框架 platform-leader-research；上市地 US。不构成投资建议。

## 12.1 一句话匹配

分板块质量高（北美生态成熟、AWS 护城河仍宽且增速再加速），颠覆敞口 **中高**（主在 **AI capex 回报时滞** 与零售/广告两端分流），成长情景中性收入约 **12–16%**、接近卖方；中性 SOTP ~**$2.9T** 对现价 **$2.83T** 大致持平——**更像「优质平台在 AI 资本周期中的合理价」，而非深度折价或纯泡沫。**

## 12.2 摘要与回扣

| 回扣 | 要点 |
|------|------|
| 04 成熟主业 | 北美中低速；广告抬利润质量 |
| 05 颠覆 | 最危险：开支→FCF 证伪；云+零售双杀 |
| 06 护城河 | 北美中偏宽、国际中、AWS 宽但可被价格/自建侵蚀 |
| 08 情景 | 主业锚 + AWS 方差；不外推 +37% |
| 09 SOTP | 中性略高于市值；贵在云期权 |
| 11 涨跌 | 近端宏观 β；中期开支叙事 |

**乐观对照：** AWS 维持高强度增长且 2027 起 FCF 明显转正 → 期权溢价扩张。  
**谨慎对照：** Capex 再上修 + AWS 增速快速回落 → 倍数与现金流双杀。

## 12.3 前提与风险

**中性前提：** ① 北美份额与广告不大崩；② AWS 未来 2–3 年仍显著快于零售；③ 净债可控、无强制融资危机；④ 投资收益波动不改变经营判断。

**可证伪风险：** ① Capex/收入比持续恶化；② AWS 增速掉到高 teens 且指引疲软；③ 广告诉讼实质削弱变现；④ 折扣电商显著分流核心品类。

## 12.4 跟踪表

| 信号 | 看多确认 | 看空确认 |
|------|----------|----------|
| AWS 增速 / 指引 | 维持高二十或更好，OI 利润率稳住 | 连续减速超预期、利润率急压 |
| Capex / FCF | 指引见顶、TTM FCF 转正 | 再大幅上修、FCF 更深流出 |
| 北美/广告 | 广告双位数、履约效率改善 | 广告增速塌、监管强制改产品 |
| 估值与催化 | 10-29 后开支叙事缓和 | 财报后市场重定价「只烧钱不增收」 |
| 竞争 | 份额稳定、自研芯片外销进展 | 大客户迁云或自建放量 |
