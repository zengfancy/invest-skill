# 7. 治理与资本配置｜亚马逊（AMZN）

> 本分册对应 Step 7。

## 7.1 股东回报

| 项 | 现状 |
|----|------|
| 现金分红 | **无** |
| 股本 | 约 10.79B；同比 **+0.88%**（StockAnalysis）→ 近端更像稀释/股权激励净增，而非大力回购年 |
| Buyback yield | 披露为负约 −0.9%（股本增加） |
| 与 FCF | TTM FCF 净流出时，大规模回购空间有限；资本优先给 AI/云基建 |

**读法：** 当前定价不靠「高股东现金回报」，靠增长与长期再投资叙事。

## 7.2 再投资与战投

| 方向 | 证据 |
|------|------|
| 核心再投资 | FY2026 现金 capex 指引约 **$220B**（7 月自 ~$200B 上修，主因内存等组件成本） |
| Q2 现金 capex | 约 **$53.1B** |
| AI / Chips | 管理层称 AI 与芯片业务 run-rate 各超 **$25B** |
| 战投 | Anthropic 等投资；Q2 non-op 其他收益 **$53.4B**（抬高净利，**≠经营质量**） |
| 零售履约 | 同日达/次日达、生鲜与日用加快；无人机等为远期期权 |

## 7.3 治理

| 项 | 要点 |
|----|------|
| 控制权 | 贝索斯仍为重要股东/影响力人物；CEO Andy Jassy 经营执行 |
| 内部人持股 | 约 **8.9%**；机构约 **68%** |
| 红旗关注 | 投资组合公允价值波动对 EPS 的干扰；大型诉讼（广告等）治理披露 |

## 7.4 组织阶段

明确处于 **再扩张年**（云/AI 产能），不是纯提效年。对 Step 8：利润率路径取决于 AWS 收入消化产能的速度，以及零售广告能否继续补贴履约成本。
