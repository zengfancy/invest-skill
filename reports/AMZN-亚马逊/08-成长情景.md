# 8. 成长情景｜亚马逊（AMZN）

> 本分册对应 Step 8。禁止一条「公司整体增速 xx%」糊弄。中性为主。

## 8.1 强制拆分（未来约 3 年）

| 部分 | 中性假设 | 依据 / 触发 |
|------|----------|-------------|
| **北美（成熟）** | 收入 CAGR **8–12%**；OI 增速可略快（广告与效率） | 份额高、广告仍增但基数已大 |
| **国际（过渡）** | 收入 CAGR **8–13%**；OI 利润率缓慢抬升 | 提效成功则 OI 弹性大；价格战则扁平 |
| **AWS（增长期权）** | 收入 CAGR **20–28%**（前高后缓）；OI 利润率中枢高双位数～低四十 | Q2 +37% 难永续；产能与竞争决定斜率 |
| **集团合计** | 收入 CAGR 约 **12–16%**；经营利润 CAGR 约 **15–22%** | 云权重大则上限打开 |

| 情景 | 触发条件 |
|------|----------|
| 乐观 | AWS 维持接近 30%+ 更久；广告诉讼无实质伤害；capex/收入比 2027 后回落、FCF 转正 |
| 悲观 | AWS 增速快速回落到高 teens；零售流量被分流；capex 再上修且利用率不足 |

投入期新业务（无人机、部分设备、卫星等）：标为 **期权**，中性情景 **不并入** 主业永续高增。

## 8.2 与一致预期对照

| 来源 | 数字 | 对照 |
|------|------|------|
| 卖方 3Y 收入增长预测 | ~**15.4%** | 与中性区间 **接近略偏上沿** |
| 卖方 3Y EPS 增长预测 | ~**22.8%** | 含投资收益与利润率假设噪音；应用 **OI** 交叉验证 |
| Q3 公司指引 | 收入 +9–12%（含 Prime Day/汇率）；OI $22.5–26.5B | 短单季偏保守，不等于中期崩塌 |

**写破：** 主业（零售）贡献收入锚与部分利润；**估值方差与叙事主要在 AWS/AI**。禁止把单季 AWS +37% 外推为集团永续。
