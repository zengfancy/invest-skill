# 4. 成熟主业分析｜亚马逊（AMZN）

> 本分册对应 Step 4。成熟锚：**North America**（及利润贡献仍小的 International）。AWS 作第二曲线，不在此章当「无限赛道」外推。

## 4.1 North America（成熟现金锚）

| 必答 | 内容 |
|------|------|
| 份额与天花板 | 美国电商份额已高；增量更多来自品类渗透（生鲜/日用）、配送速度、广告与会员，而非「互联网刚启动」 |
| 变现与定价 | 自营毛利 + 3P 佣金/履约 + **广告** + Prime 订阅；广告 Q2 +26% 是利润质量关键 |
| 利润率与效率 | FY25 OI $29.6B（占收入约 7%）；H1 2026 OI $17.4B，利润率仍显著低于 AWS，但绝对额厚、趋势向上 |
| 现金流 | 零售占用营运资本与履约网络 capex；集团 FCF 目前被 AWS/AI 基建主导，不能把负 FCF 全算在零售头上 |
| 中性增速（3 年） | 收入大致 **高个位数～低双位数**；经营利润可略快于收入（广告与履约效率），**禁止**用电商整体 GMV 故事外推 20%+ 永续 |

**若没有 AWS：** 北美仍是高周转、中利润率的平台零售+广告公司，估值应贴近优质零售/广告复合体，而非云软件倍数。

## 4.2 International（过渡中的次成熟）

| 必答 | 内容 |
|------|------|
| 份额与天花板 | 多国市场成熟度不一；对标本地巨头与跨境玩家，空间在份额与利润率，不在「从零渗透」 |
| 变现 | 与北美类似；广告与履约密度决定利润率 |
| 利润率 | FY25 OI 仅 $4.75B（利润率 ~3%）；已扭亏巩固，但远未到北美水平 |
| 中性增速 | 收入 **高个位数～低双位数**（含汇率噪音）；OI 弹性来自提效，方差大于北美 |

## 4.3 成熟主业合读

FY25 零售两分部合计收入 **$588B**、OI **$34.4B**，仍是收入主体；但 OI 已不到集团一半。成熟主业叙事应是：**稳住份额与客心智、广告与履约提效贡献中低速利润增长**——第二曲线（AWS）负责估值方差。
