# 3. 近 1–2 年重大变化｜亚马逊（AMZN）

> 本分册对应 Step 3。核心：赚钱结构、资本密度、监管哪项发生难逆变化。

## 3.1 转折时间线

| 时间 | 事件 | 财务/经营印证 | 周期还是结构 |
|------|------|---------------|--------------|
| 2024–2025 | 零售利润率修复、国际扭亏为盈巩固 | FY25 Intl OI $4.75B；NA OI $29.6B | **结构**（提效兑现） |
| 2025 全年 | AWS 增速中枢 ~20%；AI 开支抬升 | FY25 AWS +20%；FCF $11.2B（前一年 $38B） | **结构**（资本密度↑） |
| 2026 H1 | AWS 增速逐季爬升至 Q2 **+37%** | Q2 ARR 年化 ~$169B；AI/Chips 各 >$25B run-rate | **结构**（AI 需求） |
| 2026-07-30 | Capex 指引升至约 **$220B**；TTM FCF 转负 | TTM FCF −$7.6B；Q2 现金 capex $53.1B | **结构** |
| 2026-07-30 | Q2 净利暴增 | Non-op $53.4B（Anthropic 等） | **周期/会计**（非经营） |
| 2026-08-31 | FTC+22 州起诉广告拍卖 | 广告 FY25 $68.6B、Q2 +26% | **结构风险**（监管） |
| 2026-10 | 宏观+AI 开支叙事压制 Mag7 | 股价距高点约一成；估值近多年低位叙事 | 周期+结构定价 |

## 3.2 周期 vs 结构

| 类型 | 内容 |
|------|------|
| 周期 | Prime Day 季度错位、汇率（Q3 指引约 −80bps）、短期通胀/利率 β |
| 结构 | AI 资本开支常态化、AWS 利润权重大幅上升、广告监管敞口、零售「更快配送」资本与成本曲线 |

## 3.3 检查清单

| 项 | 结论 |
|----|------|
| 新品类/新业务 | AI 云与自研芯片 run-rate 各超 $25B；无人机等仍早期 |
| 渠道/竞争 | 折扣电商与即时零售分流北美；国际区域分化 |
| 提效 | 2023–25 零售提效已部分兑现；当前矛盾转回开支 |
| 回购分红 | 无常规现金分红；股本同比略增（+0.9%），非大力回购年 |
| 监管 | 广告拍卖诉讼；反垄断叙事延续 |
| 组织 | Jassy 持续「客户+长期投资」叙事，资本配置偏向 AWS/AI |

## 3.4 与市场预期

已定价大半：AWS 再加速、广告高增。增量博弈：**$220B capex 的回报时滞**、Q3 指引偏保守是否只是日历噪音、FCF 何时转正。投资收益波动易造成「EPS 好看、现金难看」的预期差。

## 3.5 结构变化结论

过去两年亚马逊从「零售利润率修复故事」切到「**AI 资本开支换 AWS 加速**」：利润结构更像云平台，自由现金流叙事暂时让位于产能建设。
