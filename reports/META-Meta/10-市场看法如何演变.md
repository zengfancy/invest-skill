# 10. 市场看法如何演变｜Meta（META）

## 10.1 证据

| 类型 | 内容 |
|------|------|
| 卖方 | ~63 人 Strong Buy；目标价均值 **$815** |
| 一致预期 | 3Y 收入 ~22%；EPS ~10.5%（利润率承压已部分进入模型） |
| Q3 业绩 | 收入超预期；GAAP OI 受诉讼拖累；FCF 转负；Capex 下限上移 |
| 治理 | Class C 宣布——融资能力↑、稀释担忧↑ |
| 盘后 | 收盘 $697.52 → 盘后约 **$713（+2%）**，偏「收入强对冲开支噪音」 |

## 10.2 叙事轴

1. **效率年修复**（2023–24）→ 费用纪律  
2. **广告 AI 加速**（2025）→ 收入与利润率双回升  
3. **AI 军备开支**（2026）→ Capex/FCF 再定价  
4. **诉讼 + Class C**（2026-08～10）→ 现金义务与资本结构进入定价  

## 10.3 预期差

卖方收入路径偏乐观于本报告中性；EPS 路径已承认开支。本报告更强调 **FCF 与 Class C 稀释** 作为主预期差，而非否认广告动能。
