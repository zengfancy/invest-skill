# 4. 成熟主业分析｜Meta（META）

成熟锚：**Family of Apps（广告为主）**。

| 必答 | 内容 |
|------|------|
| 份额与天花板 | 全球社交/短视频广告份额已高；增量靠 AI 推荐、新表面变现、WhatsApp、价与量，而非「社交从零渗透」 |
| 变现 | 广告拍卖（展示 +10%、单价 +14%）；WhatsApp 付费消息/订阅（Q3 其他收入 $1.1B） |
| 利润率 | FY25 FoA OI 利润率 ~**52%**；Q2 ~39%、Q3 GAAP ~27%（诉讼+AI 成本）——中枢被开支压低 |
| 现金流 | 历史上 FoA 贡献几乎全部 FCF；当前集团 FCF 被 Capex 主导 |
| 中性增速（3 年） | 广告收入 **高双位数前段、逐步回落到中高个位数～低双位数**；禁止把 +26% 外推永续 |

**若没有 AI/RL 叙事：** FoA 仍是顶级数字广告平台，估值应贴近高利润率广告龙头，倍数低于「超智能期权」故事。
