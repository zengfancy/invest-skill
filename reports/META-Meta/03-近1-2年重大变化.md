# 3. 近 1–2 年重大变化｜Meta（META）

## 3.1 时间线

| 时间 | 事件 | 印证 | 周期/结构 |
|------|------|------|-----------|
| 2024–2025 | 广告 AI 效率提升、收入加速 | FY25 收入 +22%、FoA OI $102B | **结构** |
| 2025 | Capex 抬升服务 AI/数据中心 | FY25 FCF $43.6B（低于 FY24 $52B） | **结构** |
| 2026-05 | 裁员约 **8,000** | Q2 遣散费 $1.18B；Q3 末人头 6.68 万（−15% YoY） | **结构** |
| 2026-08 | 与 52 州检察和解 | 合计最高约 **$18.6B**；Q3 计提 **$9.89B** | **结构/法律** |
| 2026 Q2–Q3 | AI Capex 冲高 | Q3 Capex $34.9B；FCF −$2.1B | **结构** |
| 2026-10-21 | Q3：收入强、推 Class C、收窄 Capex 区间 | 收入 $64.6B；Capex 指引 **$135–145B**；Muse 模型 | **结构** |

## 3.2 周期 vs 结构

| 周期 | 广告宏观、假期季 Q4、汇率（Q4 指引约 −1% 头风） |
|------|------|
| 结构 | AI 资本密度、Class C 融资架构、诉讼现金义务、RL 资源向 AI 再配置 |

## 3.3 检查清单

| 项 | 结论 |
|----|------|
| 新品 | Muse / Muse Wonder 前沿模型；AI 眼镜增长、Quest 偏弱 |
| 提效 | 裁员降人头，但基建与第三方 AI token 成本上升 |
| 回购分红 | Q3 分红 $1.36B；Q3 **无回购**（H1 亦显示回购暂停迹象） |
| 监管 | 青少年诉讼部分落地；仍有青年相关案件排期 |
| 治理 | **Class C 无投票权股** 用于融资/薪酬/并购，巩固创始人控制 |

## 3.4 结论

从「效率年广告修复」切到「**AI 军备 + 法律买单 + 资本结构改造**」：FoA 需求仍强，自由现金流与治理叙事已成定价主轴。
