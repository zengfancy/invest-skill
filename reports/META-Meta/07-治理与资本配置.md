## 7.2 再投资与融资

| 方向 | 证据 |
|------|------|
| Capex | FY26 **$135–145B**（自 $130–145B **收窄并抬高下限**）；Q3 $34.9B |
| 债务 | 长期债 9 月末 **$80.9B**（年末 2025 为 $58.7B）；H1 发行净额约 $24.9B |
| Class C | 2027-01-19 起设无投票权 Class C；1:1 股票股利后 Class A 价格近似 **2 拆 1**；用于融资/薪酬/并购 |
| RL | FY26 亏损指引 $18–19B；FY27 约 $15B，资源向 AI 倾斜 |
| 诉讼现金 | AG 和解最高约 $18.6B（Q3 已确认费用 $9.89B） |

## 7.3 治理

双重股权 + 拟设 Class C：**强化创始人长期控制**，同时打开不稀释投票权的融资通道——对少数股东是双刃剑（战略稳定 vs 潜在经济稀释）。

## 7.4 组织阶段

**再扩张年（AI）** + 局部提效（裁员）。FoA 利润率路径取决于广告 AI 增量能否跑赢基建折旧与第三方算力成本。
