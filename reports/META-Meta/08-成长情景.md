# 8. 成长情景｜Meta（META）

## 8.1 拆分（约 3 年）

| 部分 | 中性假设 | 触发 |
|------|----------|------|
| **FoA 广告** | 收入 CAGR **12–18%**（前高后缓） | AI 变现延续；竞争与监管约束 |
| **FoA 其他** | 高增但基数仍小 | WhatsApp 商业化节奏 |
| **Reality Labs** | 收入低；亏损 FY27 ~$15B 量级 | 标为期权，不并入主业永续高增 |
| **集团** | 收入 CAGR 约 **12–18%**；OI 增速低于收入（开支密度） | |

| 情景 | 触发 |
|------|------|
| 乐观 | 广告维持 20%+ 更久；Capex 2027 后见顶；FCF 回升；RL 亏幅快于指引收窄 |
| 悲观 | Capex 再上修；广告减速至高个位数；Class C 大额发行；新诉讼 |

Q4 公司指引收入 **$73–76B**；剔诉讼后 FY26 OI 仍望高于 FY25。

## 8.2 与卖方对照

| 来源 | 数字 | 对照 |
|------|------|------|
| 卖方 3Y 收入增长 | ~**22%** | **高于**本报告中性上沿 |
| 卖方 3Y EPS | ~**10.5%** | 反映利润率/开支压力；与「收入高增、利润更慢」一致 |

**写破：** FoA 是锚；**AI Capex 与 RL 贡献方差与拖累**。禁止把单季广告 +26% 外推永续。
