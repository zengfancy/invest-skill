# 12. 综合判断与跟踪清单｜谷歌 / Alphabet（GOOGL）

> 本分册对应 Step 12。框架 platform-leader-research；上市地 US。不构成投资建议。

## 12.1 一句话匹配

分板块质量高（Services 利润率极高、Cloud 增速与 backlog 强），颠覆敞口 **中高**（主在 **搜索入口 AI 化** 与 **天量 Capex→FCF**），成长情景中性收入约 **14–20%**（低于卖方 ~23%）；中性 SOTP ~**$4.6T** 对现价 **$4.09T** 略高——**更像「优质平台在 AI 资本周期中的合理略便宜」，但现金回报已被开支压制，绝非无风险便宜。**

## 12.2 摘要与回扣

| 回扣 | 要点 |
|------|------|
| 04 成熟主业 | Services 中高个位数～低双位数；Search 是锚 |
| 05 颠覆 | 最危险：入口代际 + Capex 证伪 |
| 06 护城河 | Search/YouTube 宽；Cloud 中偏宽变宽中；Other 未定 |
| 08 情景 | 卖方收入预测偏乐观；本报告更抠 Cloud 斜率 |
| 09 SOTP | 中性略高于市值；贵在云/AI |
| 11 涨跌 | 近端让产叙事；中期盯 Capex |

**乐观：** Cloud 持续高增且 2027 起 FCF 改善、Search RPM 稳住。  
**谨慎：** Capex 再上修 + 搜索变现密度下滑 + 让产拖累 Cloud。

## 12.3 前提与风险

**中性前提：** ① Search 份额与广告商工具链不崩；② Cloud 仍显著快于 Services；③ 净现金/融资能力覆盖开支；④ 股权浮盈不改变经营判断。

**可证伪风险：** ① Capex/收入比持续恶化、FCF 长期为负；② Cloud 增速快速掉档；③ Search 增速与 RPM 双降；④ 监管强制改广告产品形态。

## 12.4 跟踪表

| 信号 | 看多确认 | 看空确认 |
|------|----------|----------|
| Cloud 增速 / backlog | 高增延续、交付跟上 backlog | 增速急刹、让产导致丢单 |
| Capex / FCF | 指引见顶、季度 FCF 转正 | 2027 再大幅上修、FCF 更深流出 |
| Search / ads | 双位数且 RPM 稳定 | AI 体验导致变现密度下滑 |
| 融资 / 稀释 | 不再大规模股权融资 | 持续 ATM/可转优先股扩容 |
| 催化 | 10-28 后开支叙事缓和 | 财报强化「只烧钱」定价 |
