# 6. 分板块竞争与护城河｜谷歌 / Alphabet（GOOGL）

> 本分册对应 Step 6。

## 6.1–6.2 分板块表

| 板块 | 竞争烈度 | 护城河 | 主要对手 | 变薄路径 |
|------|----------|--------|----------|----------|
| Google Services（Search） | **中高** | **宽**：默认入口、广告商工具链、数据飞轮 | Microsoft Bing/Copilot、Apple 分发、AI 原生助手 | AI 旁路查询；RPM 下降；分发分成上升 |
| YouTube | **中** | **宽**：创作者网络、长视频心智、客厅设备 | TikTok、Meta Reels、流媒体广告 | 短视频时长分流；品牌预算迁移 |
| Google Cloud | **高** | **中偏宽→变宽中**：AI 全栈+TPU+模型；份额仍落后 AWS/Azure | AWS、Azure、Oracle；客户自建 | 产能不足丢单；价格战；第三方算力压利润率 |
| Other Bets | **高（未定）** | **未定/窄**：Waymo 等尚在兑现 | Tesla Robotaxi、传统车企、Cruise 余波 | 商业化慢于开支 |

## 6.3 定量交叉

| 线索 | 读法 |
|------|------|
| Services OI 利润率 ~42% | 护城河已兑现为利润 |
| Cloud OI 利润率 Q2 35.6%（去年同期 ~21%） | 规模与产品结构改善快；第三方算力或短期压利润率 |
| Cloud backlog $514B | 需求侧强；交付与产能是瓶颈 |
| Network −1% | 该子业务护城河变薄中 |
