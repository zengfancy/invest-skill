# 7. 治理与资本配置｜谷歌 / Alphabet（GOOGL）

> 本分册对应 Step 7。

## 7.1 股东回报

| 项 | 现状 |
|----|------|
| 分红 | 普通股季度 **$0.22**（2026-07 宣布）；另有强制可转优先股股息 |
| 回购 | 股本同比约 **−0.6%**（StockAnalysis buyback yield ~0.6%） |
| 股东现金回报 / 市值 | 分红+回购合计约 **0.8%** 量级，远低于历史「高 FCF 回购」印象 |
| 与 FCF | TTM FCF $53B 仍正，但单季已负；回报空间让位于 Capex |

## 7.2 再投资与融资

| 方向 | 证据 |
|------|------|
| Capex | FY2026 指引 **$195–205B**（自 $180–190B 再上修）；Q2 $44.9B |
| 结构 | 技术基础设施中服务器约 60%、数据中心/网络约 40%（电话会） |
| 股权融资 | 2026-06 净额 **$49.6B**（A/C 股 + 强制可转优先股） |
| 债权 | Q2 高级无抵押票据净额 **$20.3B** |
| ATM | 最高 $40B 额度，主要为员工股权税；截至 Q2 末尚未动用 |
| Other Bets | Waymo 等持续投入；FY25 有大额员工补偿相关费用 |

## 7.3 治理

| 项 | 要点 |
|----|------|
| 股权结构 | 双重股权；内部人约 **9.9%**；机构约 **66%** |
| 经营 | CEO Sundar Pichai；DeepMind 算力优先级上升为资本配置政治核心 |
| 红旗关注 | 投资组合浮盈扰动 EPS；大规模融资后的稀释与优先股条款；AI 披露诉讼 |

## 7.4 组织阶段

**再扩张年**：算力与模型优先。对 Step 8：利润率路径取决于 Cloud 消化产能速度，以及 Services 广告密度是否被 AI 体验侵蚀。
