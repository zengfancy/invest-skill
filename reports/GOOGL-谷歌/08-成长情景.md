# 8. 成长情景｜谷歌 / Alphabet（GOOGL）

> 本分册对应 Step 8。中性为主；禁止一条集团增速糊弄。

## 8.1 强制拆分（约未来 3 年）

| 部分 | 中性假设 | 依据 / 触发 |
|------|----------|-------------|
| **Google Services** | 收入 CAGR **9–13%**；OI 利润率高位略有波动 | Search 双位数难永续；订阅继续贡献 |
| **Google Cloud** | 收入 CAGR **30–45%**（前高后缓）；OI 利润率中高双位数 | Q2 +82% 含 TPU 与低基数，难直线外推 |
| **Other Bets** | 收入仍小；OI 亏损或缓慢收窄 | 标为期权，不并入主业永续 |
| **Alphabet-level** | AI 共享成本绝对值上升 | 压合并利润率 |
| **集团合计** | 收入 CAGR 约 **14–20%**；经营利润 CAGR 约 **12–18%** | Cloud 权重大则上限打开 |

| 情景 | 触发 |
|------|------|
| 乐观 | Cloud 维持极高增且 2027 起 FCF 明显改善；Search AI 扩查询且 RPM 不塌 |
| 悲观 | Capex 再大幅上修；Cloud 因让产/竞争失速；Search 变现密度下滑 |

## 8.2 与一致预期对照

| 来源 | 数字 | 对照 |
|------|------|------|
| 卖方 3Y 收入增长预测 | ~**22.8%** | **高于**本报告中性上沿 → 卖方更乐观（偏 Cloud） |
| 卖方 3Y EPS 增长 | ~**18.4%** | 含投资收益噪音；应用 **OI** 交叉 |
| 公司 | 未给收入正式指引；强调 2027 Capex 仍显著上升 | 现金叙事偏谨慎 |

**写破：** Services 是估值锚；**Cloud/AI 贡献叙事方差**。禁止把 Cloud +82% 外推为集团永续。
