# 4. 行业空间与竞争格局｜英伟达（NVDA）

> Step 4。不构成投资建议。

## 4.1 空间桥

| 层 | 内容 |
|----|------|
| TAM | 全球 AI 训练/推理资本开支；公司/卖方常引用远期「万亿级 AI 基建」口径（需视为愿景非承诺） |
| 可参与 | GPU 集群 + 网络 + 软件；主权云与企业 ACIE |
| 产品 | Blackwell Ultra / Vera Rubin；Spectrum 网络；CUDA/软件 |
| 份额 | 训练侧仍主导；推理与定制 ASIC 竞争加剧 |
| 收入 | 近端由供应释放节奏决定；Q3 指引 $108B |

禁止：「AI 很大所以永远值 5T」。

## 4.2 竞争

| 对手类型 | 代表 | 烈度 |
|----------|------|------|
| 通用加速器 | AMD Instinct 等 | 中高，份额仍低 |
| 云自研 | Google TPU、Amazon Trainium、Microsoft Maia 等 | **高**（长期份额侵蚀风险） |
| 中国国产 | 华为昇腾等 | 中国市场高；全球外溢有限 |
| 网络/系统 | 博通等以太网/定制 | 中（部分协同、部分替代） |

## 4.3 集中度

买方高度集中于少数超大规模云与 AI 实验室 → 议价与自研激励强。卖方在高端训练 GPU 仍高度集中于英伟达（精确全球市占第三方完整表未取得，以经营事实与卖方共识定性）。
