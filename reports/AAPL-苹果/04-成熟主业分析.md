# 4. 成熟主业分析｜苹果（AAPL）

成熟锚：**iPhone（及整体硬件生态）**。

| 必答 | 内容 |
|------|------|
| 份额与天花板 | 全球高端手机份额已高；增量靠换机、新兴市场、ASP，而非「智能手机从零渗透」 |
| 变现 | 硬件毛利 + 带动 Services；涨价可提 ASP，也伤量 |
| 利润率 | Products 毛利率约高三十；合并 OI 利润率 TTM ~33% |
| 现金流 | 硬件驱动经营现金，回购主引擎；Capex 相对收入极低（轻资产组装模式） |
| 中性增速（3 年） | iPhone/硬件收入 **中个位数～高个位数**；禁止把 Q3 +22% 外推永续 |

**若没有 Services/AI 叙事：** 苹果仍是顶级消费电子现金牛，但合理倍数应显著低于当前 ~37× 前瞻 PE。

Services 虽高增，已具成熟现金牛特征（FY25 +14%、毛利率 ~75%），在 Step 8/9 作「主业内高利润块 + 轻度期权」处理，而非未兑现故事。
