# 7. 治理与资本配置｜苹果（AAPL）

## 7.1 股东回报

| 项 | 现状 |
|----|------|
| 分红 | 季度 $0.27；年化约 $1.08，yield ~**0.3%** |
| 回购 | 9M FY26 **$62.1B**；股本同比约 **−2.1%** |
| 股东现金回报 | 回购+分红约 **2.4%** 市值 — 在 Mag7 中仍属「回报友好」 |
| 与 FCF | TTM FCF $137B 完全覆盖回购；**非**负 FCF 叙事 |

## 7.2 再投资

| 方向 | 证据 |
|------|------|
| Capex | TTM 仅约 **$10B** — 相对收入极低（代工模式） |
| R&D | Q3 单季 $11.7B（+32%），AI/硅片/系统 |
| 并购 | 新任 M&A 负责人（媒体报道）；非主叙事 |

## 7.3 治理

股权分散、机构持股约 66%；Tim Cook 经营层。无双重投票权争议（相对 META）。资本配置纪律长期清晰：**巨额回购 + 克制分红 + 低 Capex**。

## 7.4 组织阶段

硬件换机年 + AI 软件投入年并行；费用率因 R&D 抬升，靠毛利率与回购支撑 EPS。
