## 9.1 SOTP（中性）

以 TTM/前瞻经营利润拆分假设：Services 归因 OI 约 **$65B**（高毛利），硬件归因 OI 约 **$90B**（余下合并 OI 量级；TTM OI $155B）。

| 板块 | 方法 | 关键指标 | 倍数假设 | 隐含价值 | 依据 |
|------|------|----------|----------|----------|------|
| Services | EV / 归因 OI | **$65B** | **26×** | **~$1.69T** | 高毛利订阅/商店；监管折价 |
| Hardware（iPhone 等） | EV / 归因 OI | **$90B** | **22×** | **~$1.98T** | 成熟硬件；换机周期折价 |
| 净现金 | | | | **+$0.06T** | |
| **隐含股权** | | | | **~$3.73T** | |
| 当前市值 | | | | **$5.02T** | |

### 敏感性

| 情景 | Services / Hardware | 约略股权 |
|------|---------------------|----------|
| 偏紧 | 22× / 18× | ~$3.1T |
| 中性 | 上表 | ~$3.7T |
| 偏松（品牌溢价） | 30× / 28× | ~$4.5T+ |

即使用偏松硬件 28× + Services 30×，仍难轻松撑到 **$5T**，除非给硬件显著高于历史的「AI 永续溢价」。

## 9.2 贵在哪？

- 中性 SOTP **明显低于**市值（约 **−25%** 量级）→ 现价已计入厚重品牌/生态/AI 期权。  
- **更贵部分：** iPhone 周期与 Apple Intelligence 叙事溢价。  
- **锚：** Services + FCF/回购；若仅按 FCF $137B × 25× ≈ $3.4T 量级，与中性 SOTP 同向。

**结论句：** 更像「优质现金牛被给出成长股顶部倍数」；对换机证伪的脆弱性 **高于** 对明年 Services 能否继续双位数的脆弱性。
